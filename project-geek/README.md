# Project GEEK

Official Project GEEK microsite hosted inside `EgoShiftLabs/egoshiftlabs.github.io`.

**Public URL:** https://egoshiftlabs.github.io/project-geek/

Project GEEK is an independent retro-futurist culture project inspired by the collision between a 1973 automation story and modern AI/robotics. The site includes the public whitepaper, GEEK Files format, launch doctrine, original mascot and brand canon.

## Deployment state

The site intentionally does not publish a token contract before deployment. When the official Solana contract exists, update the contract status in `index.html` and commit the verified address once, exactly as deployed.

## Brand rule

Use the original Project GEEK mascot and visual system. Historical entertainment references are commentary/context, not project-owned IP.
